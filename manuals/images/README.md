# Images folder for Admin Manual

Simpan semua screenshot dan ilustrasi di folder ini.

Aturan singkat:
- Gunakan nama file lowercase, pisahkan dengan dash.
- Format yang direkomendasikan: png, jpg, svg.
- Maks lebar: 1200px untuk screenshot.

Contoh:
- dashboard-overview.png
- user-add-form.png

Cara menambahkan:
1. Salin file gambar ke folder ini.
2. Referensi di manual: ./images/nama-file.png
